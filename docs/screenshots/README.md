# Captures de la documentation

Les captures présentes dans ce dossier montrent uniquement des pages publiques sans données personnelles :

- `accueil.png` : page d’accueil publique ;
- `chatbot.png` : assistant public ouvert.

Les espaces candidat, recruteur et administrateur ne sont pas capturés depuis la production, car ils peuvent afficher des identités, candidatures, documents, adresses email ou informations de configuration.

Pour compléter la documentation, utilisez un environnement de démonstration avec des comptes fictifs et des données anonymisées. Vérifiez chaque image avant de la versionner : aucun email réel, numéro de téléphone, CV, secret, jeton, identifiant de session ou détail de candidature ne doit être visible.
