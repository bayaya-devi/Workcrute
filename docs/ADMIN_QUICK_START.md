# Workcrute — démarrage rapide administrateur

## Se connecter

1. Ouvrez [https://workcrute.pages.dev/admin/connexion/](https://workcrute.pages.dev/admin/connexion/).
2. Saisissez le secret de niveau 1.
3. Validez puis saisissez le secret de niveau 2.
4. N’enregistrez pas les secrets sur un ordinateur partagé.

## Voir l’activité

Ouvrez **Tableau de bord** pour les indicateurs et le flux en direct. Ouvrez **Journal d’activité** pour l’historique des actions sensibles.

## Modifier un candidat

Ouvrez **Candidats**, recherchez le nom ou l’e-mail, cliquez sur la fiche puis sur **Modifier**. Enregistrez et vérifiez le résultat. Utilisez **Suspendre** seulement lorsqu’il faut couper l’accès au compte.

## Modifier un recruteur

Ouvrez **Recruteurs**, recherchez le compte, ouvrez sa fiche puis modifiez les informations autorisées. Les changements sont journalisés.

## Créer un questionnaire

Ouvrez **Questionnaires**, cliquez sur **Créer un modèle**, renseignez le nom et les trois langues, ajoutez les questions puis testez les conditions. Activez l’autorisation recruteur uniquement quand le modèle est prêt.

## Gérer la FAQ

Ouvrez **Chatbot**, recherchez une FAQ puis utilisez **Modifier**, **Activer**, **Désactiver** ou **Supprimer**. Renseignez toujours question, réponse et mots-clés en FR, EN et AR.

## Changer l’email admin

Ouvrez **Paramètres > Emails**, saisissez la nouvelle adresse et lancez la vérification. Récupérez le code reçu, confirmez l’adresse puis envoyez un email de test.

## Lire une erreur

Ouvrez **Erreurs**. Repérez la sévérité, le service, la route et le **Request ID**. Ajoutez une note et passez le statut à **En cours**, puis **Résolue** après correction.

## Activer la maintenance

Ouvrez **Paramètres > Maintenance**, renseignez les messages FR/EN/AR, activez l’option et enregistrez. L’administration reste accessible. Désactivez la maintenance à la fin.

## Se déconnecter

Cliquez sur **Déconnexion** dans le menu administrateur. Fermez ensuite l’onglet si l’ordinateur est partagé.

> Ne placez jamais les deux secrets administrateur, un mot de passe ou un code de validation dans une note partagée.
